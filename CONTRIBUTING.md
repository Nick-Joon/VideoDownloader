# Git Commit Convention

Используем Conventional Commits.

## Типы коммитов

- `feat:` — новая функциональность
- `fix:` — исправление ошибки
- `chore:` — технические изменения и настройка
- `docs:` — изменения документации
- `test:` — добавление или изменение тестов
- `refactor:` — переработка кода без изменения поведения

## Примеры

feat: add batch download endpoint

fix: handle null url in strategy factory

chore: add serilog configuration

docs: update README with setup instructions

test: add unit tests for DownloadStrategyFactory

refactor: extract IDownloadQueue interface
